# 작업 기록 — 2026-03-10

## JSON → 코드 적용 워크플로 구체화

---

## 프로젝트 환경

- 주 용도: 이벤트 페이지 (단발)
- 프레임워크: Nuxt2 (90%), Next.js (10%)
- AI 도구: 그때그때 다름 (Claude Code, Cursor 등)

---

## 파일 배치 (Nuxt2 기준)

```
assets/
└── figma/
    ├── {페이지명}_structure.json
    ├── {페이지명}_design.json
    └── assets/
        ├── icons/      ← SVG
        └── images/     ← PNG/WebP 플레이스홀더 위치용
```

---

## AI 프롬프트 템플릿

어떤 AI 도구든 공통으로 쓸 수 있는 기본 템플릿:

```
다음 Figma 디자인 JSON을 기반으로 Nuxt2 Vue SFC 컴포넌트를 작성해줘.

## Structure (레이아웃/계층)
{structure.json 내용}

## Design (시각 스타일)
{design.json 내용}

## 조건
- Nuxt2 + Vue 2 SFC 형식 (<template>, <script>, <style scoped>)
- 스타일은 인라인 스타일 대신 scoped CSS 클래스로
- 이미지는 실제 파일 없이 플레이스홀더 주석으로 처리
- SVG 아이콘은 assets/figma/assets/icons/{name}.svg 경로로 <img> 태그
- 반응형 불필요 (이벤트 페이지 고정 너비)
```

---

## 분할 기준 (단일 파일 vs 섹션별 컴포넌트)

| 상황 | 방식 |
|------|------|
| 프레임 1개 = 전체 페이지, 작은 편 | 단일 파일 |
| 프레임이 섹션별로 나뉘어 있음 | 섹션별 컴포넌트 |
| JSON이 너무 커서 AI 컨텍스트 초과 | 강제 분할 |

**권장: 섹션별 분할** — JSON을 작게 쪼개면 AI 재현율 향상, 수정 시 해당 섹션만 재생성 가능.

## 권장 Figma 프레임 구조

```
페이지
├── hero
├── section-about
├── section-prize
└── footer
```

→ 각 프레임마다 플러그인에서 Structure/Design 개별 내보내기

---

## 전체 플로우

```
1. Figma 플러그인 → 섹션 프레임 선택 → Structure + Design 다운로드
2. assets/figma/ 에 배치
3. 위 프롬프트 템플릿에 JSON 붙여넣기
4. 생성된 코드 → pages/ 또는 components/ 에 배치
5. 이미지/SVG 에셋 수동 연결
```
