## 주요 논의

### Code Connect
팀에서 Figma의 Code Connect 기능을 사용하지 않음.
`--component-map`을 선택적 기능으로 구현해두되, 강제하지 않는 방향으로 정리.

### 이벤트 페이지 + Vue 2
- 단발성 이벤트 페이지: 컴포넌트 재사용 없이 단일 파일로 작성
- Vue 2 사용 케이스 존재 → 프레임워크 맥락은 **프롬프트에서 직접 전달**하는 방식으로 해결
- `--framework` 옵션 같은 스크립트 레벨 대응 불필요

### ai-prompt-guide.md
`SKILL.md`가 각 출력 파일의 의미와 필드를 이미 설명하므로 사실상 중복 문서에 가까움.
Figma 특유의 매핑 규칙(layoutMode → flexbox 등)도 JSON 필드 이름에서 유추 가능한 수준.

### 서브에이전트 자동화
이벤트 페이지의 시각적 QA가 수동 검수 부담이 크다는 문제 제기.
Figma PNG export → 코드 생성 → 브라우저 스크린샷 → AI 이미지 비교 파이프라인으로 해결 방향 확정.

## figma_extract.py 개선

### 1. 컴포넌트 의도 전달 — `description` 필드

```python
STRUCTURE_KEYS = { ..., "description" }
DESIGN_KEYS    = { ..., "description" }
```

Figma 컴포넌트/프레임에 설명이 있으면 JSON에 포함. AI가 "왜 이 컴포넌트를 쓰는가" 맥락 파악 가능.

### 2. 토큰 이름 어노테이션

`fetch_node()` 반환값을 `(document, styles_map)` 튜플로 변경.
`styles_map`: `{styleId → {name, styleType, ...}}` — 노드 응답의 스타일 레지스트리.

`pick_keys()` 내에서 자동 주입:
- fills에 `_tokenName` — 색상 토큰 이름 (예: `"Primary/Blue-500"`)
- TEXT 노드에 `_textToken` — 텍스트 스타일 토큰 이름 (예: `"Typography/Heading-1"`)

로컬 스타일 없는 파일에서는 조용히 스킵.

### 3. `--types tokens` — 토큰 요약 JSON

`collect_tokens()` 추가. 프레임 전체에서 사용된 토큰을 수집해 `{slug}_tokens.json` 출력.

```json
{
  "colors": { "Primary/Blue-500": { "type": "SOLID", "color": {...} } },
  "typography": { "Heading/H1": { "fontSize": 32, "fontWeight": 700 } },
  "effects": {}
}
```

### 4. `--types manifest` — 텍스트 콘텐츠 추출

`collect_manifest()` 추가. 모든 TEXT 노드의 텍스트를 평면 목록으로 추출.

```json
[
  { "name": "Hero/Title", "characters": "디자인 시스템으로 AI 업무 흐름 강화" }
]
```

텍스트 누락 검수 외에도 i18n, CMS 입력, 하드코딩 감지 등에 활용 가능.

### 5. `--component-map FILE` — 프로덕션 코드 참조 주입

컴포넌트 이름 → 프로덕션 코드 매핑 JSON 파일 로드.
매칭되는 노드에 `_codeConnect` 필드 주입.

```json
{
  "Button/Primary": {
    "import": "import { Button } from '@/components/Button'",
    "usage": "<Button variant='primary'>{label}</Button>"
  }
}
```

### 6. `--types png` — Figma 프레임 PNG 추출

`fetch_image_url()` + `download_file()` 추가.
Figma `/v1/images/` API를 호출해 @2x 해상도 PNG를 `{slug}.png`로 저장.

시각 QA 파이프라인의 기준 이미지로 사용.

## SKILL.md 업데이트

- 출력 파일 표에 `png` 항목 추가
- 토큰 어노테이션 예시 (`_tokenName`, `_textToken`)
- Code Connect 매핑 사용법 및 매핑 파일 형식
- manifest 활용 예시
- **시각 QA 파이프라인** 섹션 신규 추가

```
figma_extract.py --types structure,design,png
        ↓
executor 에이전트 → HTML/CSS 생성
        ↓
chrome-cdp → 브라우저 렌더 + 스크린샷
        ↓
AI가 {slug}.png ↔ screenshot.png 비교 → 피드백
        ↓
executor 수정 → 반복
```
